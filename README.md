# Portfolio di Alessio Avdiu

Il mio portfolio personale: presentazione, competenze e progetti di sviluppo web.

**Sito online:** https://alessio723.github.io

## Come è fatto

Sito statico, scritto a mano senza framework né librerie esterne (solo i font di Google Fonts).

- **HTML**: struttura e contenuti in una sola pagina, con sezioni Chi sono, Competenze, Progetti e Contatti.
- **CSS**: layout minimalista responsive, tema chiaro e scuro, nessuna dipendenza.
- **JavaScript**: cambio tema (salvato nel browser), voce di menu attiva durante lo scroll, anno automatico nel footer.

Attenzione particolare a: leggibilità su telefono, navigazione da tastiera, rispetto della preferenza di sistema per tema scuro e animazioni ridotte.

## Struttura

```
index.html   contenuti della pagina
style.css    stile e tema chiaro/scuro
script.js    comportamento (tema, menu attivo, anno)
```

## Provarlo in locale

1. Clona il repository o scarica i tre file nella stessa cartella.
2. Apri `index.html` nel browser, oppure usa l'estensione Live Server di VS Code.

Non servono installazioni né comandi di build.
